# SPEC-007 — SEO

- Status: Implemented (AC3 pending deployment)
- Sprint: 3
- Related: [003](./003-marketing-site.md)

## Requirements

- R1. **Base URL**: `getSiteUrl()` resolves `NEXT_PUBLIC_SITE_URL` → `https://${VERCEL_PROJECT_PRODUCTION_URL}`
  → `http://localhost:3000`. Used as `metadataBase`, in the sitemap, robots and JSON-LD.
- R2. **Metadata per route** via a `createPageMetadata({ title, description, path })` helper:
  unique `<title>` (template `%s | LGuIA`, home uses an absolute title), meta description,
  self-referencing canonical, Open Graph (`type`, `locale es_ES`, `siteName`, `url`, `title`,
  `description`) and Twitter `summary_large_image`.
- R3. **OG image**: one generated `opengraph-image.tsx` at the app root (1200×630, brand colours,
  route motif). Inherited by every route.
- R4. **Icons**: SVG `icon.svg` (route mark) + `apple-icon` PNG generated at build.
- R5. **`sitemap.ts`**: all public, indexable routes (home, services overview, 4 categories,
  plans, diagnosis, contact). Admin and API excluded.
- R6. **`robots.ts`**: allow all; disallow `/admin` and `/api`; link to the sitemap.
- R7. **Admin** pages: `robots: { index: false, follow: false }`.
- R8. **Structured data** (JSON-LD, only for visible content):
  - Organization (`ProfessionalService`) + `WebSite` — root layout.
  - `Service` per category page (provider = organization, `areaServed` Spain, catalog of the
    visible service items).
  - `BreadcrumbList` on category pages (matches visible breadcrumbs).
  - `FAQPage` on pages with a visible FAQ (category pages, plans).
- R9. **Semantics**: one descriptive `<h1>` per page, logical hierarchy, descriptive internal link
  text (no "click aquí"), `lang="es"`.
- R10. **No fabricated claims** in structured data: no ratings, reviews, prices that are not shown,
  or addresses that do not exist.
