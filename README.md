# LGuIA

Digital agency platform for SMEs and local businesses: web development, automation and practical AI.

> Work in progress — this README is completed at the end of Sprint 3. See
> [`docs/specs`](./docs/specs/README.md) for the specifications and [`AGENTS.md`](./AGENTS.md) for
> development rules.

## Development

```bash
npm install
npm run dev
```

| Script             | Purpose                                   |
| ------------------ | ----------------------------------------- |
| `npm run dev`      | Development server                        |
| `npm run build`    | Production build                          |
| `npm run check`    | Lint + typecheck + unit/integration tests |
| `npm run test:e2e` | Playwright end-to-end tests               |
